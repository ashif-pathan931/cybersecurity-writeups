## Commands Learned

### 1. `ls` — List Files

Displays files and directories in the current directory.

```bash
ls
```

### 2. `cd` — Change Directory

Moves into another directory.

```bash
cd folder1
```

To return to the parent directory:

```bash
cd ..
```

### 3. `cat` — Read File Contents

Displays the contents of a file.

```bash
cat filename
```

Replace `filename` with the actual file name.

### 4. `pwd` — Print Working Directory

Displays the current directory's full path.

```bash
pwd
```
